🎨 Image Filters

A web port of the image-manipulation algorithms from the notebooks. Everything runs locally in your browser — your images are never uploaded to any server.

Boxes 2–5 images

Splits each image into an N×N grid and combines the cells, interleaving them cyclically across the images by taking a section of pixels from each one.

Select between 2 and 5 images.
Result

With a larger N each cell is smaller and the mosaic is finer. Images are resized to a common size before combining.

Boxes by block size 2–5 images

Same interleaved combination, but choosing the block size independently for horizontal and vertical, in pixels or percentage.

Select between 2 and 5 images.
Result

In percentage mode, width is % of the image width and height is % of the height. The last block in each row/column is cropped if it doesn't fit.

Boxes Animation 2–5 images

Generates an animation of the Boxes filter by sweeping the grid's number of divisions N from a minimum to a maximum. Each value of N produces a frame; playing them back in sequence makes the mosaic progressively finer (or coarser) as it interleaves the images. Based on the boxes-frames notebooks.

Select between 2 and 5 images.
Animation
Upload images and press “Generate animation”.

With a larger N each cell is smaller and the mosaic is finer. For very long animations the number of frames is limited and the size is reduced so the browser doesn't run out of memory. Video export uses MediaRecorder and prefers MP4 (more compatible when sharing); if the browser can't record MP4 it uses WebM, and if it can't record the canvas (e.g. some iOS) use “Frame (PNG)” to save the visible frame.

4-Way Collage 1 image

Builds a mirrored 2×2 mosaic from a single image (original, horizontal flip, vertical flip, and both) and then slices it into sections that are interleaved from the outside in, producing a kaleidoscopic, symmetric collage. Port of the 4waycollage / collage_mix notebooks (see also live_collage.py).

Pick a single image.
Original
Collage

More sections make a finer, more intricate symmetry. The collage is rendered from a 2× mosaic and scaled back to the original size, so there's no distortion.

Person / Background 1 image

Detects the person in a photo with an on-device segmentation model (MediaPipe Selfie Segmentation), then lets you operate on either the person or the background — invert its colors, run it through the 4-Way Collage kaleidoscope, apply a Chroma Shift (RGB glitch), or drop it to low resolution (pixelate) — while the other part stays untouched. The model runs entirely in your browser — your image is never uploaded.

Pick a single photo containing a person.
Original
Result

Upload a photo to start — the model (~6 MB) loads on first use.

Uses MediaPipe Selfie Segmentation, self-hosted under vendor/selfie/ and loaded only when you first use this tab. Needs a browser with WebAssembly SIMD (all current browsers). Large images are processed at up to 1600 px on the long side. The raw mask is a bit rough, so refine it: threshold sets how much counts as “person”, grow / shrink dilates (+) or erodes (−) the region to cover missed bits or trim spill, and smooth edges feathers the boundary so the cut looks rounded instead of jagged. Show mask previews the refined matte (white = selected).

Person Collage Animation

Animate the 4-Way Collage on the selected region by sweeping the number of sections across a range — the person (or background) turns into a shifting kaleidoscope while the rest stays still. Uses the same photo, target and mask refinements from above; press Generate after loading a photo.

Animation

The collage is composited into the current target with the refined mask (grow/shrink + smooth edges apply). Video export uses MediaRecorder and prefers MP4; if the browser can't record the canvas (e.g. some iOS) use “Frame (PNG)”.
